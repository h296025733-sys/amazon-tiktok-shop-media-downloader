# 商品素材助手

**把商品页里属于当前商品与规格的图片、视频和信息，整理成可预览、可筛选的素材组。**

选品时，一页商品详情可能混着主图、不同规格图、详情图、评论晒单、推荐商品和品牌导航。直接下载页面上的所有图片，文件夹很快会变成一堆无法判断来源的素材。

这个 Manifest V3 扩展先识别当前 Amazon / TikTok Shop 商品，再按站点规则提取对应区域，归并同一素材的不同地址，让人预览后选择要保存的文件。商品工具栏还提供标题、链接和商品 ID 的复制入口。

项目使用原生 JavaScript，没有本地后端与框架构建链。重点在页面范围、素材身份与下载后如何整理。

## 实际使用流程

1. 打开商品详情，选择正在研究的规格。
2. 等待当前规格的图片与视频加载。
3. 点击扩展入口，或按 `Alt+Z` 打开素材选择器。
4. 按分组预览，选择单项、多项或整组素材。
5. 保存文件，并通过工具栏复制标题、链接或商品 ID。

切换规格后应重新检查预览中的素材，不同站点的规格展示和加载方式并不完全相同。提取范围以当前页面取得的资源为准，不保证取得平台未暴露的原件。

## 页面提取怎样避免“全页扫图”

| 层 | 负责什么 |
| --- | --- |
| 站点规则 | 定义商品区域、分组与排除区域 |
| 页面提取 | 从当前商品上下文收集素材与规格信息 |
| 媒体规范化 | 归并 URL、比较图片版本、去重与命名 |
| 选择界面 | 预览与决定下载范围 |
| 下载后台 | 执行浏览器下载 |

评论、推荐、导航和头像不能仅因是图片就进入商品素材。`site-profiles.js` 将这些范围与 Amazon、TikTok Shop 的页面规则放在一起，站点变化时主要在这里调整。

`content.js` 负责页面提取，`media-utils.js` 处理不同地址如何对应同一素材。平台、商品和规格信息参与文件整理，减少多个商品混到一起后无法识别的问题。

## URL 归并与高分辨率选择

同一张图片可能同时出现缩略图、预览图和较大版本，地址中又可能有裁切或尺寸参数。规范化层处理平台地址特征，将可识别的版本归并，再优先采用页面提供的更合适版本。

这是对已暴露地址的整理，不是重建不存在的高清原件。没有更大版本、资源需要登录、URL 过期或视频是分段流时，仍可能无法取得目标文件。

素材分组与规格标签一起保留，便于判断一张图来自主图、规格还是详情区域。多选时先看预览，比无差别保存整页更方便后续使用。

## 安装

1. 下载或克隆仓库到本机。
2. 在 Chrome / Edge 扩展管理页打开开发者模式。
3. 选择“加载已解压的扩展程序”，指定本仓库根目录。
4. 刷新已打开的商品页，再使用扩展入口。

仓库中的 `manifest.json` 规定了已适配域名与资源权限。页面属于未声明的区域站点或平台调整了商品结构时，可能需要补充规则；安装后应先用一份自己有权处理的商品素材确认当前站点表现。
