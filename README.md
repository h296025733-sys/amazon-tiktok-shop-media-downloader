# 商品素材助手

**把当前 SKU 的图片、视频和规格信息整理成可筛选、可批量下载的素材组。**

选品时，商品页往往混着主图、规格图、评论图和推荐商品。这个扩展先确认当前商品与 SKU，再提取对应区域的素材，让人预览之后决定保存哪些文件。

它支持 Amazon 和 TikTok Shop 商品页，使用原生 JavaScript 与 Manifest V3，不需要本地后端。商品工具栏可复制标题、链接与 ID，`Alt+Z` 打开素材选择器。

## 提取时解决的三个问题

| 问题 | 做法 |
| --- | --- |
| 页面上到处都是图片 | 站点规则定义商品区域、素材分组与排除区域，剔除评论、推荐、导航与头像。 |
| 同一张图有多个尺寸和地址 | 归并图片地址并优先选择页面提供的高分辨率版本，减少重复文件。 |
| 多商品、多规格下载后混在一起 | 文件命名与目录保留平台、商品和规格信息；支持单选、多选和分组下载。 |

站点变化主要落在 [site-profiles.js](src/site-profiles.js)，图片归并与命名在 [media-utils.js](src/media-utils.js)，页面提取在 [content.js](src/content.js)。这几层分开维护，可以在调整站点选择器时复用下载与整理规则。

## 安装与开发

在 Chrome / Edge 扩展管理页打开开发者模式，加载本仓库目录，然后刷新商品页。

```powershell
npm run check
npm test
```

项目使用 Manifest V3 和原生 JavaScript，不需要本地后端。它提取的是页面已经暴露的资源；登录限制、过期链接和分段流媒体仍可能导致下载失败。请自行确认素材使用授权。
