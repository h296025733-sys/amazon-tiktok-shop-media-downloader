# 商品素材助手

我做这个扩展，是想把选品时反复找主图、切规格、另存视频的操作放到同一个入口。打开商品详情页，切到需要的 SKU，就可以预览、筛选和下载页面已经提供的素材。

## 能做什么

- 识别 Amazon ASIN、TikTok Shop 商品 ID 和页面当前规格。
- 按 SKU 素材、商品展示、详情简介分组，支持多选和整组下载。
- 优先选择页面暴露的高分辨率原图，合并同一图片的不同尺寸。
- 在商品页提供快捷工具栏，复制标题、链接或商品 ID；`Alt+Z` 打开素材选择器。
- 按平台、商品和规格整理下载目录，减少同名文件混在一起。

站点规则分别写在 `src/site-profiles.js`，图片归并和文件命名在 `src/media-utils.js`。扩展只处理商品区域，排除评论、推荐位、导航和店铺头像。

## 安装与开发

在 Chrome / Edge 扩展管理页打开开发者模式，加载本仓库目录，然后刷新商品页。

```powershell
npm run check
npm test
```

项目使用 Manifest V3 和原生 JavaScript，不需要本地后端。它提取的是页面已经暴露的资源；登录限制、过期链接和分段流媒体仍可能导致下载失败。请自行确认素材使用授权。
